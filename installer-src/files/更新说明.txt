本次更新（beta23.8.5）

1. 强冷只保留快捷开关一个入口：自定义模式窗口里不再有强冷一项，配置里也不再保存（启动时自动清掉旧版本留下的强冷配置键）；快捷开关的状态会被记住，开机按上次的选择补发一次。
2. 风扇与采样一起理顺：占空比改成同一判据（读得到占空比就用占空比，只报转速的机型按该机型声明的额定满转折算），小窗和大窗不再出现两个数；占空比走 EC 只读兜底时不再跟刷新新鲜度联动，百分比不再一秒一闪；采样周期改由设置里的「刷新间隔」决定（0.5–4.5 秒，默认 2 秒），并修掉采样泵把自己当成「刚有人采过」而跳拍、导致实际周期被拉长到 3 秒的问题。
3. 界面按需渲染与独立刷新：宽屏性能卡片的风扇环和指示条改成平滑过渡，数值变化时按实际值滑过去不再硬跳；宽屏性能卡片和小窗的传感器读数独立按每秒 4 次取共享快照刷新，只有数值真的变了才重画；主界面狂暴档的 GPU 超频开关默认不画出来，确认在狂暴档且确有独显时才显示。
4. 文案与布局统一：显卡模式三档统一成「iGPU only / Hybrid / dGPU only」（中文：核显模式 / 混合模式 / 独显模式），宽屏与小窗一致，性能档按钮改成按内容自适应宽度，英文下不再裁掉半个字母；自定义模式窗口的「处理器最大频率」改成标题与插电／离电两个输入框同一行、提示单独一行，并补上英文；设置里的恢复基准卡片改名「自定义恢复基准」、说明重写为「切档时先按这里的值恢复，再下发新模式的设置」，每项区分「从未记录／已记录／已记录且为不限频」三种状态，重记条数的分母修正为 5 项。
5. 宽屏下点「自定义」档时默认直接跳到自定义页（切档的同时把要调的参数摆出来）；不想要这个跳转的话，设置 → 控制模式卡片里有开关可以关掉。
6. 安装包的赞助二维码放到程序真正读取的目录，装完之后赞助页不再空白。
7. 校色这一块修了一串：小窗与大窗的自定义校色改为共享同一份状态，导入或删除 ICC 后两边档位立即刷新（以前要等下一次刷新，有时干脆刷不出来）；删除自定义配置会自动关闭自定义校色并回到默认档；关掉自定义校色后下拉列表立刻回到原生档位，并自动重新关联默认校色，不再出现「校色开着却什么都没挂」；修复「云端获取 ICC」先从本地复制文件、而不是优先从云端获取的问题（现在先查云端，未命中才用本机文件兜底：本机官方目录里已下过的整包 → 程序目录自带的官方包 → Windows 颜色目录里与当前面板匹配的厂校色），结果里也会写清是云端下载还是本机复用；面板匹配只看面板 ID，换主板导致 MAC 变化后旧的校色文件仍能被认出；整包用标准名（sRGB／DCI-P3／AdobeRGB／Default）的多文件包机型也能正确挑出默认项。
