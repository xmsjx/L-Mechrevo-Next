键盘灯 EC 抓取（只读）
======================

干什么：轮询键盘灯相关寄存器，只打印“发生变化”的行，用来抓固件在按键/开关时到底写了什么。
        只读，不写任何寄存器；只用 \.ACPIDriver 的 0x700-0x7FF 窗口通道，不碰 EC 端口 I/O。

用法：
  1) 双击 run-capture.cmd（会自己请求管理员权限）
  2) 窗口出现“抓取开始”后，做这些动作：
       按 Fn 亮度键 3~4 次（关 → 亮 → 暗 → 亮 → 关）
       打开原厂控制台，点一次键盘背光电源开关，再拨一次亮度
  3) 按 Ctrl+C 结束（窗口不会关），日志在同目录 kbd-ec-capture-*.txt

命令行参数：
  -Seconds 60        抓 60 秒后自动停（默认 0 = 一直抓到 Ctrl+C）
  -IntervalMs 100    轮询间隔（默认 150 ms；太快会漏掉瞬时脉冲，太慢会漏短脉冲，150-200 比较稳）
  -Regs 0x78C,0x767  自己指定地址表（十六进制、逗号分隔，必须在 0x700-0x7FF）

默认抓的寄存器（Code01 / PF 系列）：
  0x78C  键盘电源位 + 亮度位（bit1=关灯 · bit5=档1 · bit6=档2 · bit4=提交位）
  0x767  触发/锁存字节（键盘灯动作时常有 0x20 脉冲）
  0x7AB  模式索引（按档位写入的写法会动这里）
  0x7C5  彩虹模式
  0x766  支持位/China 模式
  0x78E  单区电源支持位（bit5）
  0x740  机型项目号（对照用）

看什么：
  · 按 Fn 亮度键时 0x78C 怎么跳（例如 0x03 → 0x41 → 0x21 → 0x03）
  · 0x767 有没有脉冲、脉冲值是多少
  · 原厂控制台点开关时，除了 0x78C 还动了哪个寄存器

注意：
  · 必须以管理员运行，否则打不开驱动
  · 驱动没装时脚本会直接说“打不开 \.ACPIDriver”并退出
  · 抓完把整个 txt 发回，不要截图（日志里有毫秒时间戳和位变化）
